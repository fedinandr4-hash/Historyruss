# 📜 Исторический Таймлайн

Интерактивный веб-сайт «Исторический Таймлайн» по учебнику Мединского/Торкунова  
**«История России. 1914—1945 годы. 10 класс»**

![Музейный стиль](https://img.shields.io/badge/стиль-музейный-c49b3c)
![Событий](https://img.shields.io/badge/событий-35-8b4513)
![React](https://img.shields.io/badge/React-18-61dafb)

## Возможности

- 📅 **Таймлайн** — 35 ключевых событий 1914—1945 годов
- 🔍 **Поиск** — по названию и описанию событий
- 📖 **Фильтрация** — по главам учебника и годам
- 🤖 **ИИ-чат** — вопросы по событиям (локальная Ollama)
- 📱 **Адаптивный дизайн** — работает на мобильных устройствах

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## ИИ-чат (Ollama)

Для работы чата нужна локальная Ollama:

```bash
# 1. Установите Ollama: https://ollama.ai

# 2. Загрузите модель
ollama pull qwen3-coder:30b

# 3. Запустите Ollama (обычно работает автоматически)
# Проверьте: http://localhost:11434
```
