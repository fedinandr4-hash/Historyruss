# 📜 Исторический Таймлайн

Интерактивный веб-сайт «Исторический Таймлайн» по учебнику Мединского/Торкунова  
**«История России. 1914—1945 годы. 10 класс»**

![Музейный стиль](https://img.shields.io/badge/стиль-музейный-c49b3c)
![Параграфов](https://img.shields.io/badge/параграфов-40-8b4513)
![React](https://img.shields.io/badge/React-18-61dafb)

## Возможности

- 📚 **Структура учебника** — 3 главы, 40 параграфов
- 🔍 **Поиск** — по названиям, терминам, персоналиям
- 📖 **Раскрывающиеся главы** — параграфы открываются при клике
- 📋 **Детальная информация** — модальное окно с ключевыми датами, деятелями, терминами
- 📱 **Адаптивный дизайн** — работает на мобильных устройствах

## Структура учебника

### Глава I. Россия в годы Первой мировой войны и Великой российской революции (1914—1922)
- § 1—12: От начала войны до Гражданской войны

### Глава II. Советский Союз в 1920—1930-е гг.
- § 13—28: От НЭПа до накануне Великой Отечественной войны

### Глава III. Великая Отечественная война (1941—1945)
- § 29—40: От начала войны до её итогов

## Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

## Как использовать

1. **Просмотр глав**: Нажмите на заголовок главы, чтобы раскрыть список параграфов
2. **Просмотр параграфа**: Кликните на карточку параграфа для открытия детальной информации
3. **Поиск**: Введите запрос в поисковую строку для поиска по всем параграфам
4. **Детальная информация**: В модальном окне вы найдёте:
   - 📅 Ключевые даты
   - 👤 Ключевые исторические деятели
   - 📖 Ключевые термины и понятия
   - ✨ Основные положения

## Структура данных

Каждый параграф содержит:
- **Краткое описание** — 2-3 предложения о сути параграфа
- **Ключевые даты** — хронология событий с описаниями
- **Ключевые деятели** — исторические личности, связанные с темой
- **Ключевые термины** — основные понятия и определения
- **Основные положения** — главные выводы и тезисы

## Дизайн

Музейный стиль: тёмный фон, serif-шрифты, золотистые акценты, 
карточки в виде музейных табличек с тенями и декоративными рамками.

## Технологии

- React 18 + TypeScript
- Vite
- CSS3 (без фреймворков)
- JSON для хранения данных учебника
