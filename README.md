# 📚 Историческая Библиотека

Интерактивное веб-приложение для изучения учебников истории по учебникам Мединского/Торкунова для 10 класса.

**Доступные учебники:**
- **История России. 1914—1945 годы** (35 параграфов)
- **Всеобщая история. 1914—1945 годы** (18 параграфов)

## Возможности

- 📚 **Выбор учебника** — два учебника на выбор
- 🔍 **Поиск** — по названиям, терминам, персоналиям
- 📖 **Раскрывающиеся главы** — параграфы открываются при клике
- 📋 **Детальная информация** — модальное окно с ключевыми датами, деятелями, терминами
- 📝 **Заключения** — итоговые выводы по каждому учебнику
- 📱 **Адаптивный дизайн** — работает на мобильных устройствах

```bash
npm run dev

# Сборка для продакшена
npm run build
```

## Как использовать

1. **Выбор учебника**: На стартовом экране выберите один из двух учебников
2. **Просмотр глав**: Нажмите на заголовок главы, чтобы раскрыть список параграфов
3. **Просмотр параграфа**: Кликните на карточку параграфа для открытия детальной информации
4. **Поиск**: Введите запрос в поисковую строку для поиска по параграфам выбранного учебника
5. **Заключение**: Нажмите кнопку "📖 Заключение" для просмотра итоговых выводов
6. **Детальная информация**: В модальном окне вы найдёте:
   - 📅 Ключевые даты
   - 👤 Ключевые исторические деятели
   - 📖 Ключевые термины и понятия
   - ✨ Основные положения

## Структура данных

Каждый параграф содержит:
- **Краткое описание** — 2-3 предложения о сути параграфа
- **Ключевые даты** — хронология событий с описаниями
- **Ключевые деятели** — исторические личности, связанные с темой
- **Ключевые термины** — основные понятия и определения
- **Основные положения** — главные выводы и тезисы

## Дизайн

Музейный стиль: тёмный фон, serif-шрифты, золотистые акценты, 
карточки в виде музейных табличек с тенями и декоративными рамками.

## Технологии

- React 18 + TypeScript
- Vite
- CSS3 (без фреймворков)
- JSON для хранения данных учебника
