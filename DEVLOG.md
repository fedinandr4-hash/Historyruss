# Дневник разработки — Историческая Библиотека

## Обзор проекта
Интерактивное веб-приложение «Историческая Библиотека» для изучения учебников истории 
Мединского/Торкунова для 10 класса. Включает два учебника:
- **История России. 1914—1945 годы** (35 параграфов)
- **Всеобщая история. 1914—1945 годы** (18 параграфов)

## Технологический стек
- **Фронтенд:** React 18 + TypeScript + Vite
- **Стили:** CSS3 (музейный дизайн, без фреймворков)
- **Данные:** JSON-файл с 40 параграфами по 3 главам учебника

## Этапы разработки

### Этап 1: Структура данных
- Создан файл `src/data/textbook.json` с полной структурой учебника
- 3 главы, 40 параграфов (включая объединённые §11-12, §22-23, §25-26, §37-38, §39-40)
- Каждый параграф содержит:
  - Краткое описание (summary)
  - Ключевые даты (keyDates)
  - Ключевые деятели (keyFigures)
  - Ключевые термины (keyTerms)
  - Основные положения (mainPoints)

### Этап 2: Модуль данных
- Создан `src/data/types.ts` — TypeScript-интерфейсы
- Создан `src/data/index.ts` — функции для работы с данными:
  - `chapters` — массив глав
  - `getAllParagraphs()` — все параграфы
  - `findParagraphById()` — поиск по ID
  - `searchParagraphs()` — поиск по запросу
  - `getParagraphsByChapter()` — параграфы по главе

### Этап 3: Компоненты UI
- `App` — главный компонент с состоянием поиска
- `ChapterSection` — раскрывающаяся глава с параграфами
- `ParagraphCard` — карточка параграфа
- `ParagraphModal` — модальное окно с детальной информацией

### Этап 4: Дизайн (музейный стиль)
- Тёмный фон (#1a1714) — цвет старого дерева
- Светлый текст (#e8e0d0) — цвет старой бумаги
- Serif-шрифты (Georgia) — классический стиль
- Золотистые акценты (#c49b3c) — декоративные элементы
- Карточки с тенями и рамками — стиль музейных табличек
- Анимации: раскрытие глав, появление модального окна

## Структура файлов
```
src/
├── App.tsx           # Главный компонент
├── index.css         # Стили (музейный дизайн)
├── main.tsx          # Точка входа React
└── data/
    ├── types.ts      # TypeScript-интерфейсы
    ├── textbook.json # Данные учебника (40 параграфов)
    └── index.ts      # Функции для работы с данными
```

## Функциональность

### Просмотр глав
- Клик на заголовок главы раскрывает список параграфов
- Анимация раскрытия с плавным появлением

### Карточки параграфов
- Отображают номер, название, краткое описание
- Показывают количество дат, персон, терминов
- Клик открывает модальное окно с детальной информацией

### Модальное окно
- Полная информация о параграфе
- Ключевые даты с описаниями
- Ключевые деятели (теги)
- Ключевые термины (теги)
- Основные положения (список)

### Поиск
- Поиск по названиям параграфов
- Поиск по кратким описаниям
- Поиск по ключевым терминам
- Результаты отображаются в сетке карточек
