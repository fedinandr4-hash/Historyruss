# Дневник разработки — Исторический Таймлайн

## Обзор проекта
Интерактивный веб-сайт «Исторический Таймлайн» по учебнику Мединского/Торкунова 
«История России. 1914—1945 годы. 10 класс».

## Технологический стек
- **Фронтенд:** React 18 + TypeScript + Vite
- **Стили:** CSS3 (музейный дизайн, без фреймворков)
- **Данные:** TypeScript-модуль с 35 историческими событиями
- **ИИ-чат:** Локальная Ollama (http://localhost:11434/api/generate, модель qwen3-coder:30b)

## Этапы разработки

### Этап 1: База данных событий
- Создан файл `src/data/events.ts` с интерфейсом `HistoricalEvent`
- Заполнено 35 событий по всем трём главам учебника:
  - Глава I: Россия в Первой мировой войне и революциях 1917 года (10 событий)
  - Глава II: Россия в 1918—1941 годах (13 событий)
  - Глава III: Великая Отечественная война 1941—1945 (12 событий)
- Каждое событие содержит: id, title, date, description, location, chapter, paragraph

### Этап 2: Компонент App.tsx
- Реализован главный компонент с состоянием (useState, useEffect)
- Компонент EventCard — карточка события с форматированием даты
- Компонент ChatPanel — панель ИИ-чата с историей сообщений
- Фильтрация: по поисковому запросу, по году, по главе учебника
- Таймлайн: вертикальная линия с чередованием карточек слева/справа

### Этап 3: Дизайн (музейный стиль)
- Тёмный фон (#1a1714) — цвет старого дерева
- Светлый текст (#e8e0d0) — цвет старой бумаги
- Serif-шрифты (Georgia) — классический стиль
- Золотистые акценты (#c49b3c) — декоративные элементы
- Карточки с тенями и рамками — стиль музейных табличек
- Анимации: hover-эффекты, плавное появление чата

### Этап 4: ИИ-чат
- POST-запрос на localhost:11434/api/generate
- Модель: qwen3-coder:30b
- Промпт формируется с учётом контекста (название + описание события)
- Обработка ошибок при недоступности Ollama
- Индикатор загрузки (typing indicator)
- История сообщений в чате

## Структура файлов
```
src/
├── App.tsx           # Главный компонент (таймлайн, поиск, чат)
├── index.css         # Стили (музейный дизайн)
├── main.tsx          # Точка входа React
└── data/
    └── events.ts     # База исторических событий (35 шт.)
```

## Замечания по адаптации
Исходный запрос предполагал Python/FastAPI + Jinja2 стек. 
Проект был адаптирован под доступный React + Vite + Tailwind стек, 
сохранив всю функциональность: таймлайн, поиск, фильтрацию, ИИ-чат.

## Запуск
```bash
npm install
npm run dev        # Режим разработки
npm run build      # Сборка для продакшена
```

## Использование ИИ-чата
1. Установите Ollama: https://ollama.ai
2. Загрузите модель: `ollama run qwen3-coder:30b`
3. Убедитесь, что Ollama запущена на http://localhost:11434
4. Нажмите на любую карточку события в таймлайне
5. Введите вопрос в панели чата и нажмите «Отправить»
